# calculadora-python

Este projeto consiste em uma calculadora simples e interativa desenvolvida em Python. O foco foi aplicar conceitos fundamentais de lógica de programação para criar uma ferramenta prática e eficiente.

## 📝 O Desafio
O objetivo principal foi desenvolver uma aplicação capaz de realizar operações básicas de matemática (soma e multiplicação) e identificar o maior valor entre números informados pelo usuário, garantindo uma experiência de uso rápida e simples.

## 🛠️ A Solução
Para solucionar o problema, utilizei a linguagem de programação Python, empregando estruturas de controle de fluxo essenciais:
- `if` e `else` para realizar as verificações condicionais e lógica de comparação.
- `while` para manter a aplicação em execução e criar um menu interativo que permite ao usuário escolher as operações.

## 🎯 Resultados e Aprendizados
Como resultado, obtive uma calculadora funcional que cumpre seu propósito com eficiência. Este projeto foi fundamental para consolidar meus conhecimentos em:
- Lógica de programação.
- Estruturas condicionais.
- Laços de repetição (loops).
- Sintaxe básica e desenvolvimento em Python.
